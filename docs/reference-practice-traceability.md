# Reference Practice Evidence Map

The maintained reference-practice table is included directly in the [consolidated report](../reports/final-report.md#reference-practice-traceability). It links each practice to its equipment-project adaptation, repository/commit/PR/board evidence, sprint and result or remaining limitation.

Use the report as the single maintained table of all 13 required reference practices. The [finalization checklist](../reports/finalization-checklist.md) distinguishes completed technical evidence from report review, rehearsal and submission. Staff-access/privacy/license findings are linked through the report to [ELS-46 evidence](../reports/sprint-4/els-46-access-privacy-license-review.md).

The reference Library API assignment supplies practices. Its code, screenshots, lab tags and results are not equipment-project evidence. Historical planning versions of this map remain in Git; current evidence comes from this repository and the live ELS board.
